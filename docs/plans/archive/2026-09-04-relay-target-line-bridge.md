# 中继线路复用已有落地线路（异构协议桥接）实施记录

## 目标

为 `RELAY` 线路增加 `TARGET_LINE` 模式：入口线路保留自己的客户端协议，出口自动复用其他节点上的 `DIRECT` 目标线路协议、参数和监听端口，形成异构协议桥接，同时保护被引用的目标线路不被删除。

## 实施清单

### 数据模型与服务端

- [x] 在 `Line` 中增加 `targetLineId` 自引用关系、`relaySources` 反向关系、`Restrict` 删除规则和索引。
- [x] 增加 `TARGET_LINE` 常量、DTO 字段、目标线路合法性校验和出口节点/端口自动同步。
- [x] 增加目标线路删除拦截，并在套餐可用性判断中检查目标线路状态。
- [x] 生成 Prisma migration 并重新生成 Prisma Client。
- [x] 在 Agent 配置同步中生成入口协议入站、目标协议 outbound/route，并复用目标直连入站。
- [x] 目标节点地址变更时通过现有防抖机制刷新全部相关配置。

### 前端

- [x] 更新统一 API 类型、线路 payload 和节点线路类型。
- [x] 增加 `TARGET_LINE` 表单校验、目标线路筛选、自动绑定出口摘要和隐藏手填出口字段。
- [x] 更新线路列表、节点详情预览中的异构桥接拓扑展示。

### 文档与验证

- [x] 同步数据模型、API/协议、部署指南、前端规范、视觉验证台账和 CHANGELOG。
- [x] 补充线路服务、配置下发、节点地址变更和删除保护回归测试。
- [x] 通过完整 `pnpm gate`，并归档本规划。
