# 完善卡密：分类、奖励类型、兑换限额与软删除

## 🎯 目标与背景

补齐卡密管理中的分类、按购买身份限额、余额/套餐奖励、软删除及恢复能力。旧卡密迁移后保持原状态与兑换行为；兑换履约、额度占用和卡密核销必须原子完成，保证 SQLite 并发场景下不重复发放或突破限额。日常开发保持根版本不变，变更进入 `CHANGELOG.md` 的 `[Unreleased]`。
