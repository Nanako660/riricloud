# 订阅流量周期重置与用户额外线路

## 目标

为套餐增加自然月/订阅周期流量重置策略，并允许管理员为用户长期授权额外线路。重置只更新当前周期累计配额，不修改 `TrafficLog`；额外线路授权独立于订阅生命周期保存。

- [x] 实现共享时间计算、惰性/定时重置，并保证心跳账务事务一致性。
